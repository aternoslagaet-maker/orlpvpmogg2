# orlpvpmogg — Attribute Swap History (Fabric, MC 1.21.11)

Клиентский мод для Minecraft **1.21.11** (Fabric, Java 21), который:

- записывает **историю действенных атрибут-свапов**: «оружие → оружие» (меч → булава и т.п.) плюс любые свапы с копьём (в т.ч. щит → копьё);
- считает **время (Δ) между свапами** и отдельно **время между свапами копья** (предмет с `spear`/`trident` в id: деревянное/железное/незеритовое копьё, трезубец, включая модовые);
- **минималистичный HUD** в левом верхнем углу: [иконка] → [иконка], Δ последнего свапа, зелёный `Δ рывок · серия N` и строка `рывок: N°` — угол взгляда с цветовой отметкой: **зелёный** — ровно горизонт (хорошо для рывка), **жёлтый** — чуть вниз (до 15°) или сильно вверх (> 10°), **оранжевый** — вниз до 30°, **красный** — круто вниз; строка видна, пока в истории есть рывки;
- **окно истории** по клавише — по умолчанию **O** (переназначается в `Настройки → Управление → Раскладка клавиш`, категория «Разное»): постранично, каждая строка — иконки «было → стало», время, Δ, зелёный флажок для свапов с копьём;
- **в историю пишутся только рабочие свапы**: рывок-свапы и свапы ради дальности (с учётом удара ЛКМ), а также обычные «оружие → оружие» типа меч → булава. **Служебные свапы без атаки (копьё → щит, щит → копьё и т.п.) НЕ пишутся** и не рвут серию рывков; тултип по-прежнему показывает диф чар (без Починки и Рывка) — копьё/трезубец всегда считаются оружием, поэтому записывается даже свап щит → копьё:
  - **рывок-свап**: удар ЛКМ, затем (≈ пол-тика, окна до 400 мс) слот с копьём — только такой свап даёт `⚑ рывок`, серию и Δ рывков; простая смена слота на копьё без удара записывается как обычный свап, но НЕ считается рывком;
  - **свап ради дальности**: удар ЛКМ и слот одновременно (окно до 150 мс), копьё → булава/топор — маркер «дальность», в тултипе указан тайминг удара (не влияет на серию рывков); в тултипе каждого свапа видно «удар ЛКМ был за N мс до свапа».
- **выбор слотов хотбара в окне истории**: две кнопки сверху — «Копьё: любой/слот N» (кликнинье циклит слоты 1–9/любой) и «Свап-предмет: любой/слот N». Если у копья нестандартный id (не содержит `spear`), укажите слот с копьём — свапы с участием предмета из этого слота будут считаться копьё-свапами; настройка действует в течение сессии игры;
- **наведите курсор на запись** — подсказка сравнивает чары двух предметов и показывает **разницу** (без «Починки» и без «Рывка»): «Появились» — чары, которые есть на новом предмете, но не было на старом; «Пропали» — наоборот. Одинаковые чары с обоих предметов не засоряют подсказку;
- **копьё на Рывок** — дополнительно: в момент свапа проверяется **кулдаун снятого предмета** (например, заряда ветра) и сравнивается с «обычной рукой»: `КД снятого предмета: нет` = эффективный свап (зелёный), `есть — свап неэффективен` = предмет был на кулдауне (красный, ⚠ `КД!` на HUD и в строке истории);
- **серия** — подряд идущие рывок-свапы. Пауза между рывками, при которой серия рвётся, задаётся кнопкой «Пауза серии» в окне истории (3с/5с/10с/20с/выкл, по умолчанию 5с) — служебные свапы внутри цикла не записываются и серию не сбрасывают. `Δ рывок` на HUD — время между двумя последними рывками (весь цикл целиком);

История хранится в памяти игры: до 500 записей за сессию (в окне — постранично). Кнопки: `<`, `>`, «Очистить», «Закрыть».

## Структура

```
src/main/java/org/example/ronin/
  OrlPvpClient.java      — входная точка: клавиша, тик-события, HUD
  SwapTracker.java       — детект свапа предмета в главной руке (каждый тик)
  SwapHistory.java       — хранилище записей + интервалы + форматирование
  HudOverlay.java        — отрисовка HUD
  SwapHistoryScreen.java — экран истории (пагинация, очистка)
src/main/resources/
  fabric.mod.json
  assets/orlpvpmogg/lang/ru_ru.json, en_us.json
```

Миксинов нет — только события Fabric API (`ClientTickEvents`, `HudElementRegistry`, `KeyBindingHelper`).

## Сборка и запуск

- **IntelliJ IDEA** (File → Open → папка проекта). IDEA сама подтянет Gradle.
- Gradle **9.x** (fabric-loom 1.14-SNAPSHOT). Если своей обёртки нет, выполните в корне:
  ```
  gradle wrapper --gradle-version 9.2.1
  ```
- JDK **21** (File → Project Structure → SDK 21, Language Level 21).
- Запуск клиента: задача `runClient` из панели Gradle или `./gradlew runClient`.
- Сборка jar: `./gradlew build` → `build/libs/orlpvpmogg-1.0-SNAPSHOT.jar`.

Gradle скачает Minecraft 1.21.11, yarn-маппинги `1.21.11+build.6`, loader `0.20.1` и Fabric API `0.141.6+1.21.11` (значения из `gradle.properties`).

## Что считается свапом

Свап фиксируется, когда меняется **предмет** в главной руке (по `Item`, не по стакну). Смена количества или починка предмета того же типа свапом не считается. Свапы, где с/на копьё (или трезубец) — помечаются зелёным, и их Δ учитывается в «Δ копьё».
