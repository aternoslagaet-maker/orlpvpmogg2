# ORL PvP Attribute Swap History (orlpvpmogg)

Клиентский Fabric-мод для Minecraft Java **1.21.11** (Java 21). Записывает историю **атрибут-свапов**, считает
время между свапами и рывками, помогает тренировать тайминги. Работает через Fabric API, без миксинов.

## Что делает мод

### Детект и запись
- Записывает **только рабочие свапы**: удар + смена слота, либо замена одного оружия на другое.
- **Рывок (⚑)**: удары ЛКМ, затем (примерно в пределах полутsкачки, ≤400 мс) свап **на копьё**. Красная пометка
  **КД!** — если у снятого предмета был кулдаун (неэффективный свап).
- **Дальность**: удар ЛКМ + одновременный свап **с копья** (≤150 мс) — радиус копья переносится на новый предмет.
- В подсказке при наведении сравнивают зачарования предметов («Появились» / «Пропали», без Починки и Рывка).
- Для рывка определяется **причина красной пометки**: слишком рано (предмет ещё на КД) или слишком поздний переход.
- **Серия рывков** и Δ между рывками; порог между свапами настраивается («Пауза серии»).

### HUD (для боя)
- Верхний левый угол: иконки «было → стало» + Δ.
- **Профили HUD** (одна кнопка/клавиша периферии):
  - **Минимал для боя** — только иконки и Δ;
  - **Полный анализ** — + Δ рывка/серии, КД!, живой аим `рывок: N°` (зелёный/жёлтый/оранжевый/красный),
    рекорд пары (`РЕКОРД -Nмс`) и прогресс цели.
- Переключение: клавиша «Переключить профиль HUD» (по умолчанию не назначена) или кнопка в настройках мода.
- **Перетаскивание**: вкладка «Настройки» → зажми ЛКМ на HUD и тяни в любое место; кнопка «Вернуть HUD в угол» сбрасывает позицию. Позиция хранится в конфиге.
- **Диагноз свапа** (показывается прямо в HUD, обоих профилях): почему приём не получился —
  «Нет удара ЛКМ перед свапом», «Поздно свапнул на копьё (удар за N мс)», «КД: слишком рано — снятый предмет ещё остывает»,
  «КД: поздний переход — удар за N мс», «Поздно ударил (N мс) — дальность не засчитана»,
  «Дальность: слот поздновато». Красный — критично, жёлтый — было проведено, но с косяком.
  Служебный свап (копьё → щит и т.п.) диагноз не трогает — причина последнего рывка остаётся на экране;
  рывок, засчитанный, но медленный (>150 мс), подсвечивается жёлтым «Свап с опозданием — удар за N мс (оптимум ~40)».
  Удар старше 1 с считается «удара не было» — старые свапы не помечаются ложным «поздно».
- **Свап без задержек**: рывок засчитывается и в обратном порядке — слот + ЛКМ одновременно/почти одновременно
  (удар до 400 мс после нажатия слота). Так же пишется в историю, серия, рекорды и играет звук.
- **Свапы оружия на копьё запрещены полностью**: булава/меч/топор → копьё никогда не записывается и не дает диагноз — это служебный возврат.
- **Прогноз Pearl Catch** (заряд ветра + жемчуг Эндера): после броска жемчуга и заряда в HUD пишется прогноз,
  получится ли трюк — «Перлинг: поймаю ✓ (~20 блоков)» (зелёный; при разгона прыжком на заряде — «усиленный ~30»),
  «поздно, заряд за N мс» (жёлтый, окно 500 мс), «прицел низкий/низковат (N°)» (оранжевый; надо почти вертикально вверх).
- **Попадание при свапе ради дальности**: после свапа с копья на оружие в HUD пишется «Дальность: попал по цели ✓» (зелёный)
  или «Дальность: не попал по цели» (оранжевый). Для свапа ради рывка такая строка не показывается.
- **Служебные свапы на копьё не записываются**: свап на копьё без удара ЛКМ в окне 400 мс не попадает в историю и HUD.
- **Серия рывков** растёт только по **эффективным** рывкам: неэффективный (КД) не увеличивает серию и обрывает её.
- Свап ради дальности тоже поддерживает порядок «слот → ЛКМ» (удар до 150 мс после слота).

### Звук
- Короткий звук при **эффективном** рывке (более высокий тон при зелёном аиме).
- Едва слышный низкий тон при **неэффективном** (КД).
- Звук при **засчитанном свапе ради дальности** (тон 1.3).
- Низкий тон при **неудачном** свапе (поздний удар/слот на дальности, поздний свап на копьё).
- Выбор звука свапа: нотный блок, колокол (золото под нотным), плинг, головы мобов (зомби/скелет/крипер/
  эндер-дракон/визер-скелет/пиглин) или обычный клик — кнопка «Звук свапа» в Настройках, при переключении играет превью.
- Включение/выключение и громкость (10–100%) — в Настройках мода.

### Окно истории (клавиша O, по умолчанию; в Настройках клавиш можно переипять)
- Три вкладки: **История**, **Статистика**, **Настройки**.
- **История**: пагинация, иконки, Δ, ⚑ рывок/дальность, серия, КД; наведение — подробная подсказка
  (перенос зачарований, тайминг удара, аим, рекорд пары, причина красной пометки).
- **Статистика**:
  - счётчики: рывков, «Свапов ради дальности: N», % эффективных КД-скипов, лучшая серия;
  - **Avg Δ / Median Δ за сессию** (переключается кнопкой) + лучший Δ сессии;
  - накопительная статистика за всё время (из alltime-файла);
  - **эталоны**: «Идеальный 1-тик» (50 мс) и «Стабильный PvP» (250 мс);
  - **диаграмма аима**: полоса с долями зелёного/жёлтого/оранжевого/красного аима и проценты.
- **Экспорт**: кнопка пишет `config/orlpvpmogg/stats.txt` (отчёт сессии) и объединяет счётчики в
  `config/orlpvpmogg/alltime.txt`. Файлы можно отправить друзьям/тренеру.
- **Настройки**: слот копья и свап-предмета, пауза серии, профиль HUD, звук, громкость, цель (тренировка).

### Цели (челленджи)
- Пять уровней: Разминка (10×Δ≤300) → Стабильность (20×Δ≤200+зелёный аим) → Идеал (20×Δ≤150+зелёный)
  → Мастер (30×Δ≤100+зелёный), плюс «ВЫКЛ».
- Прогесс в полном HUD («Цель: 7/20»), при выполнении — сообщение на экран + звук; можно сбросить.

### Рекорды пар
- Для каждой пары «было → стало» хранится лучший Δ: `config/orlpvpmogg_records.json`.
- В полном HUD: `Δ: 120 мс (РЕКОРД -5 мс)` — гонка с самим собой.

### Конфиг
- `config/orlpvpmogg.json` — все настройки (слоты, серия, HUD, звук, громкость, цель, прогресс, позиция HUD).
- Мод Menu (если установлен) открывает это же окно через «Настройки мода».

## Сборка
```bash
./gradlew build          # jar: build/libs/orlpvpmogg-1.0-SNAPSHOT.jar
./gradlew runClient      # запуск в dev-среде
```

## Управление
- **O** — история свапов (переназначается в Настройки → Управление).
- Клавиша «Переключить профиль HUD» — минимал/полный (по умолчанию не назначена).
- Рывок: удар ЛКМ → через ~пол-тика свап на копьё. Дальность: удар + свап одновременно.
